## 📋 Sobre o Projeto

Este projeto consiste no desenvolvimento de um sistema para ajudar lojas a organizarem e controlarem seus produtos de forma mais profissional.

O sistema foi pensado para facilitar o gerenciamento de estoque, permitindo cadastrar, editar, excluir e pesquisar produtos.

---

# 🎯 Objetivo

Criar um sistema para ajudar uma loja a organizar e controlar seus produtos de maneira simples, prática e eficiente.

---

# ⚙️ Principais Funcionalidades

O sistema possui as seguintes funcionalidades:

- ➕ *Cadastrar produtos:* adicionar novos produtos ao sistema.
- ✏️ *Editar produtos:* alterar informações de produtos já cadastrados.
- 🗑️ *Excluir produtos:* remover produtos do sistema.
- 🔎 *Pesquisar produtos:* encontrar produtos com mais facilidade.
- 📦 *Ver quantidade em estoque:* verificar quantas unidades estão disponíveis.
- ⚠️ *Aviso de estoque baixo:* alertar quando um produto estiver acabando.
